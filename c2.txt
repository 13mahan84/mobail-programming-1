تمرین ۶:

نوع String برای متغیرهایی استفاده می‌شود که مقدار آن‌ها نباید null باشد؛ اما String? اجازه می‌دهد متغیر مقدار null داشته باشد.
fun main() {
    val name: String = "Ali"
    val lastName: String? = null

    println(name)
    println(lastName)
}
